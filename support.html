Before the first install

  • Use the same email address Norris Stand invited for your customer record when you open the customer portal.
  • If a Norris Stand sign-in or invite email does not arrive within a few minutes, check Spam, Junk, and Promotions, then search for Norris Stand. Make sure you are using the same email address Norris Stand invited.
  • Expect the Windows app to ask for portal approval before monitoring starts on a new PC.
  • Have the Google account ready that should own the Drive destination for this setup.
  • If you are not sure whether you have access yet, contact hello@norrisstand.com before you try to activate the app.
01

Install and activate this PC

Run the official installer, open the app, and use Activate this PC or Re-activate this PC so the Norris Stand portal can approve the installation for the customer record.

02

Add a Google account and destination

Use Add Google account, sign in with the approved Google account, then either choose an existing Drive destination or use Create Drive folder if the account has no folder ready yet.

03

Map source folders and start monitoring

Add one or more local source folders, confirm each Drive subfolder path, and then use Start monitoring. If Sync files already in the source folder when monitoring starts is enabled, existing files will upload on that start.

Common questions

  • If you do not have a Norris Stand invite yet, contact support first. The app is designed to activate against an approved customer record.
  • If you need pricing details or more Google account slots than the standard plan includes, review the pricing page or contact Norris Stand before rollout.
  • If a Google account shows Sign in needed, select that account and use Reconnect selected.
  • If the Drive destination does not exist yet, use Create Drive folder inside the app instead of leaving the setup flow.
  • If uploads are queued after a temporary issue, use Retry queued uploads. If you need help, use Export support bundle and send the saved ZIP to Norris Stand support.
  • Use Exit app when you want Drive Folder Sync fully stopped. Quiet mode only changes visibility and startup behavior.
  • Use Check for updates in the app for the easiest upgrade path, or download the latest installer from this site for a fresh install.
