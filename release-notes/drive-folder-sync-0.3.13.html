Drive Folder Sync 0.3.13

An update-feed reliability release for newly published installers.

Published on August 24, 2026.

Download 0.3.13 Checksum

Highlights

  • The updater now adds a one-time timestamp to the manifest request so a freshly published release is not hidden behind a briefly stale cached manifest.
  • This makes Check for updates pick up the newest live installer more reliably right after a release goes out.
  • No setup, activation, or sync workflow changed beyond the update-feed freshness fix.

Included improvements

  • The manifest request now preserves any existing query settings while replacing only the cache-busting timestamp value.
  • The updater test suite now covers the manifest-request URL builder so this behavior stays locked in.
  • The release packaging and verification flow remain the same as the earlier updater hardening work.
