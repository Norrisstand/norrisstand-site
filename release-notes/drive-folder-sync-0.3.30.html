Drive Folder Sync 0.3.30

Faster, quieter monitoring restarts.

Published October 6, 2026 by NORRISSTAND LLC.

Download 0.3.30 Checksum

What changed

  • When monitoring starts, Drive Folder Sync now checks existing files against what it has already synced for each Google account and queues only new or changed files. Unchanged files are no longer queued or uploaded again.
  • New and changed files begin syncing while the startup check continues, and files created or edited as monitoring starts are picked up.
  • Unchanged files left in the queue by an earlier version are cleared quickly, and the startup check keeps an existing queued retry on its current retry schedule.
  • The status line now shows how many files the startup check found unchanged and how many are pending sync.
  • Preserves protected activation, Google credential storage, mappings, and established sync behavior. Files deleted locally remain in Google Drive.
  • The installer and project-owned Windows binaries are signed by NORRISSTAND LLC.

Updating

Existing installations can update from within Drive Folder Sync, or you can download the latest installer from NorrisStand.com and install it directly over the existing installation. Do not uninstall first. Your activation and settings should be preserved.
