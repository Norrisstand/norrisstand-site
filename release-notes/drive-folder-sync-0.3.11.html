Drive Folder Sync 0.3.11

A second updater stability pass before outside rollout.

Published on August 24, 2026.

Download 0.3.11 Checksum

Highlights

  • The in-app updater now waits for both the running app and its launcher companion to exit before starting the Windows installer.
  • Launcher-started app sessions now pass launcher context into the update handoff so setup does not race a still-closing launcher process.
  • This release is specifically aimed at making the normal in-app update path behave cleanly for real customers.

Included improvements

  • The launcher now starts the app with a launcher PID argument so the app knows which companion process must finish closing during updates.
  • The hidden installer helper now accepts multiple PIDs and waits until all of them are gone before launching setup.
  • Updater regression coverage was expanded to validate the multi-PID wait command structure.
