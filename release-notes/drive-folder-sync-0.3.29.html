Drive Folder Sync 0.3.29

Reliable secure activation on more Windows installations.

Published October 6, 2026 by NORRISSTAND LLC.

Download 0.3.29 Checksum

What changed

  • Fixes a secure-connection error (“certificate verify failed”) that could stop activation on some Windows installations, even when a web browser on the same computer could reach Norris Stand.
  • Drive Folder Sync now also trusts the standard public certificate authorities it ships with, in addition to the Windows certificate stores. Certificate and hostname verification remain required for activation, account, diagnostic, and update connections.
  • Preserves protected activation, Google credential storage, mappings, and established sync behavior.
  • The installer and project-owned Windows binaries are signed by NORRISSTAND LLC.

Updating

Existing installations can update from within Drive Folder Sync, or you can download the latest installer from NorrisStand.com and install it directly over the existing installation. Do not uninstall first. Your activation and settings should be preserved.
