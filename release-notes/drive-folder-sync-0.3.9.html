Highlights

  • The Norris Stand website now explains the official invite, portal approval, setup, download, and support path more clearly for new customers.
  • The customer portal now gives more helpful next-step guidance and official support links after sign-in.
  • Packaged Norris Stand builds now show a clear reinstall or support message if their bundled Google setup assets are missing.

Included improvements

  • The homepage, support page, downloads page, and product page now tell a more consistent onboarding story.
  • The portal sign-in and email-sent screens now use more customer-ready wording and hide local-development mail notes outside console-mail mode.
  • The packaged app no longer falls back to customer-facing prompts for a Google JSON file, Picker API key, or project number when the bundle is incomplete.
