Norris Stand Drive Folder Sync Downloads Release Notes

Drive Folder Sync 0.3.2

Customer onboarding setup fix.

Published on August 23, 2026.

Download 0.3.2 Checksum

Highlights

  • The packaged Norris Stand build now includes the official Google OAuth desktop client, so users are not asked to browse for a JSON file.
  • The packaged Norris Stand build now supplies the official Google Picker API key and project number automatically during Drive destination selection.
  • The in-app Quick Start guide now matches the real customer-facing setup experience.

Included improvements

  • Development fallback remains available, so if the bundled OAuth file is missing the app can still prompt for a local JSON file.
  • The earlier destination-first setup guard remains in place, so source folders are added only after an account has a Drive destination.
  • This release is intended to support a true first-run test as if the user were a brand-new customer.
