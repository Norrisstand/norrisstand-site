Drive Folder Sync 0.3.34

Sync single files, stricter update checks, and a clearer folder table.

Published November 15, 2026 by NORRISSTAND LLC.

Download 0.3.34 Checksum

What changed

  • You can now sync a single file, not only a whole folder. Click Add source file beside Add source folder and pick one or more files; only the files you pick are synced, not the rest of the folder they sit in. The mappings table shows whether each source is a folder or a file.
  • If a source file is renamed, moved or deleted on your PC, its row shows File not found and everything else keeps syncing. Its Drive copy is never deleted, and it syncs again by itself when a file with that exact name is back in the same folder.
  • A file that is already inside a synced folder of the same Google account cannot also be added on its own, so each file has one Drive destination per account.
  • Updates are accepted only when they are signed by exactly NORRISSTAND LLC. Any download that fails this check is deleted, and the verified signer is recorded in Activity.
  • Exported support logs no longer include file names in their "Synced" and "Will retry" lines.
  • The folder table headers are easier to read, long paths are shortened in the middle, and the table scrolls sideways when needed. The app no longer shows a price; pricing is on NorrisStand.com.
  • Requires Windows 10 version 1809 or later. Preserves protected activation, Google credential storage, mappings, and established sync behavior. Renamed or moved files are still uploaded as new Drive copies, and files deleted locally remain in Google Drive.
  • The installer and project-owned Windows binaries are signed by NORRISSTAND LLC.

Updating

Existing installations can update from within Drive Folder Sync, or you can download the latest installer from NorrisStand.com and install it directly over the existing installation. Do not uninstall first. Before updating, close Drive Folder Sync in any other signed-in Windows session. Your activation and settings should be preserved.
