Drive Folder Sync 0.3.19

Set it up once, then keep it running.

Published on August 26, 2026.

Download 0.3.19 Checksum

What changed

  • After a new customer completes the first successful monitoring start, Drive Folder Sync automatically turns on Windows sign-in startup and quiet background mode.
  • Sync setup now follows the same order customers use: add a Google account, choose or create the Drive destination, then add local source folders.
  • Select a mapping row to review complete local and Drive paths in the new Mapping details section. Hovering a shortened table cell also shows its full path.

For customers

Continuous sync runs while you are signed in to Windows and the PC has network access. You can open the app from the Norris Stand tray icon, change startup settings later, or choose Exit app when you want it fully stopped.
