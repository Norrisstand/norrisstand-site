Drive Folder Sync 0.3.7

A leaner installer with the same customer workflow.

Published on August 24, 2026.

Download 0.3.7 Checksum

Highlights

  • The Windows installer is now much smaller, which makes publishing and downloading updates more reliable.
  • Unused Google discovery cache files and extra Qt assets were removed from the packaged bundle.
  • The customer setup flow stays the same, including activation, Google sign-in, Drive folder creation, and per-source Drive mapping.

Included improvements

  • No new customer prompts were added for OAuth JSON files, API keys, or project numbers in the packaged build.
  • The release pipeline now produces a cleaner versioned installer for the official Norris Stand update feed.
  • This release is intended as a packaging and release-hardening update, not a behavior change for daily use.
