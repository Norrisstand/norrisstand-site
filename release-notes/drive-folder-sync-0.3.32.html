Drive Folder Sync 0.3.32

One app per user, safer updates, and a clearer status bar.

Published October 7, 2026 by NORRISSTAND LLC.

Download 0.3.32 Checksum

What changed

  • Only one Drive Folder Sync now runs for each Windows user, even when it is started in different ways or from another signed-in Windows session. Opening it again brings the existing window forward, or explains that it is already running in another session.
  • Before installing an update, Drive Folder Sync checks that no other copy of it is still running. If one is, or if this cannot be confirmed, it keeps running with monitoring unchanged and asks you to close the other window first.
  • The installer now stops before changing any files if Drive Folder Sync is still running, including in another Windows session, and tells you to close it and run the installer again.
  • The status bar now shows only the monitoring state and the number of files pending sync. When the startup check finishes, one plain summary in Activity reports how many existing files were checked, how many were already up to date, and how many new or changed files were found.
  • Includes the 0.3.30 improvements to monitoring restarts. Preserves protected activation, Google credential storage, mappings, and established sync behavior. Files deleted locally remain in Google Drive.
  • The installer and project-owned Windows binaries are signed by NORRISSTAND LLC.

Updating

Existing installations can update from within Drive Folder Sync, or you can download the latest installer from NorrisStand.com and install it directly over the existing installation. Do not uninstall first. Before updating, close Drive Folder Sync in any other signed-in Windows session. Your activation and settings should be preserved.
