Drive Folder Sync 0.3.18

A smoother, more reliable start to monitoring.

Published on August 26, 2026.

Download 0.3.18 Checksum

What changed

  • Opening Drive Folder Sync a second time now keeps the existing app instance in control instead of starting another sync worker.
  • Starting monitoring now shows clear progress while Norris Stand access, Google account capacity, Drive mappings, and existing-file scanning are prepared.
  • Temporary network interruptions are retried when the app verifies access or prepares Google Drive folders.
  • Microsoft Office temporary lock files beginning with ~$ are skipped instead of appearing as upload failures.

For customers

If a real saved file remains queued after a few minutes, use Export support bundle in the app and send the ZIP to Norris Stand support. Office lock files are not customer documents and do not need to be uploaded.
