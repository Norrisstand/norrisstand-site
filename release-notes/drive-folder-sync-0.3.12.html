Drive Folder Sync 0.3.12

An update reliability release for the normal in-app upgrade path.

Published on August 24, 2026.

Download 0.3.12 Checksum

Highlights

  • The in-app updater now depends on the improved app-and-launcher shutdown coordination introduced in the previous updater fix work.
  • This release keeps the multi-process installer handoff in place while moving the public release line onto that corrected path.
  • It is intended to make the normal Check for updates flow behave like a clean handoff instead of a file-lock loop.

Included improvements

  • The release metadata and update feed now point to a build created after the app-and-launcher wait logic was fully in place.
  • The launcher-aware installer handoff remains covered by updater regression tests.
  • No customer-facing workflow changes were added beyond updater reliability.
