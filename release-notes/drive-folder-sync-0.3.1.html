Drive Folder Sync 0.3.1

Google setup flow hotfix.

Published on August 23, 2026.

Download 0.3.1 Checksum

Highlights

  • The app now fills in the Google Cloud project number automatically from the saved Google sign-in.
  • Adding a source folder now requires a Drive destination first, which keeps setup in the right order.
  • The in-app Quick Start guide and project documentation now match the updated setup flow.

Included improvements

  • The destination picker still uses the official Google Picker flow, but the app now removes the extra manual project-number step.
  • First-time setup now better matches the Norris Stand activation and customer portal onboarding flow.
  • This release is intended as a packaging-ready hotfix before broader tester rollout.
