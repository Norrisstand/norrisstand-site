Drive Folder Sync 0.3.4

Destination resync fix.

Published on August 24, 2026.

Download 0.3.4 Checksum

Highlights

  • Changing the Google Drive destination now resets the saved sync history for that account.
  • Existing source files can now populate the newly selected or newly created destination when monitoring starts again.
  • The app now logs that destination reset so support and testing are easier to verify.

Included improvements

  • This fix applies to both Choose Drive folder and Create Drive folder.
  • Source-folder mappings remain in place; only the account's prior upload history is reset when the destination changes.
  • This release addresses the behavior observed during live customer-style onboarding tests on August 24, 2026.
