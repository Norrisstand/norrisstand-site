Drive Folder Sync 0.3.0

Activation and customer portal release.

Published on August 23, 2026.

Download 0.3.0 Checksum

Highlights

  • Norris Stand activation is now required per PC before monitoring begins.
  • Added the live customer portal for secure magic-link sign-in and device approval.
  • Added customer records, seat-based licensing, and registered-device tracking in the admin portal.
  • Added background license heartbeat checks so revoked or expired access is enforced by the app.
  • Added customer-portal and activation actions directly inside the Windows app.

Included improvements

  • The app now stores activation state separately from Google account connections and local folder mappings.
  • The Quick Start guide now explains activation, portal use, and what happens when the app fully exits.
  • The Norris Stand website and update feed are aligned with the activation-enabled installer release.
  • The default license seat count is two devices, which supports common desktop-and-laptop use.
  • Internal onboarding is now ready for end-to-end production testing against the live portal.
