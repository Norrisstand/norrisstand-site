Drive Folder Sync 0.3.5

Clearer folder mappings.

Published on August 24, 2026.

Download 0.3.5 Checksum

Highlights

  • The sync setup area now shows a real folder-mapping table instead of a simple list.
  • Each row shows the Windows source folder, the selected Drive destination root, the Drive subfolder path, and the final Drive target.
  • This makes it much easier to review what will sync where before monitoring starts.

Included improvements

  • The quick start guide now explains how the mapping table works.
  • The guide also now calls out the current model more clearly: one Drive destination root per Google account, with per-source folder paths under that root.
  • This release is aimed at making multi-folder and multi-account setups easier to understand during onboarding.
