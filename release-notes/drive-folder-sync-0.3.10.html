Drive Folder Sync 0.3.10

An updater stability release before public rollout.

Published on August 24, 2026.

Download 0.3.10 Checksum

Highlights

  • The in-app updater now exits more cleanly before handing control to the Windows installer.
  • The installer launch path now waits for the running app process to fully stop before setup begins.
  • The packaged launcher now recognizes update-triggered shutdown as intentional instead of immediately trying to restart the app.

Included improvements

  • Added a dedicated update-exit code so the launcher can distinguish a normal update handoff from an unexpected app failure.
  • Added a hidden Windows helper launch path that waits for the app PID to exit before starting the installer.
  • Added regression coverage for updater launch commands and launcher restart behavior so this path is easier to keep stable.
