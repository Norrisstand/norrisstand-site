Drive Folder Sync 0.3.3

First-time Drive destination creation update.

Published on August 24, 2026.

Download 0.3.3 Checksum

Highlights

  • Added Create Drive folder to the Windows app so a first-time customer can make a new top-level Google Drive destination without leaving the setup flow.
  • The newly created folder is immediately set as the destination for the selected Google account.
  • The Quick Start guide and setup instructions now explain both choosing an existing Drive folder and creating a new one.

Included improvements

  • The packaged Norris Stand build still avoids the manual JSON-file, API-key, and project-number prompts during normal customer onboarding.
  • The existing destination-first setup guard remains in place, so source folders are added only after an account has a Drive destination.
  • This release closes the empty-Google-Drive onboarding gap discovered during first-run customer testing.
