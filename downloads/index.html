Before you run the installer

  • Use this website as the official download source instead of older forwarded copies.
  • New PCs still need activation approval through the Norris Stand customer portal before monitoring begins.
  • If you are an existing customer, the easiest upgrade path is usually Check for updates inside the app.
  • If you are evaluating the product or need more Google account capacity, review the pricing page before rollout.
  • If you are not sure whether your email is already approved for access, contact hello@norrisstand.com before you install.
